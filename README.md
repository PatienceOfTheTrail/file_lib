# File Lib

created by PatiencOfTheTrail

The program reads files from a folder, sorts them by file type and appends the file names as an entry to four text files:
- compressed_and_archive.txt 
- documents_and_office.txt
- pictures_and_media.txt 
- system_and_else.txt

Those text files are stored in the folder data. Further more a feather file is created as library.
